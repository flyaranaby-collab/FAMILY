# 우리가족 플래너 (안드로이드 앱)

가족이 함께 쓰는 일정·할 일·장보기·냉장고 플래너입니다. 거실 벽에 세워 두는 대시보드 화면과 할머니·할아버지용 큰 글씨 화면도 들어 있어요.

## APK 받기
휴대폰에서 아래 링크를 누르면 바로 내려받아집니다. (로그인 필요 없음)

**https://github.com/flyaranaby-collab/family/releases/latest/download/family-planner.apk**

받은 파일을 열고 '출처를 알 수 없는 앱 설치'를 허용하면 설치됩니다.

## 기능
- 무료: 가족 공유 캘린더, 할 일 + 담당자, 장보기 실시간 공유, 음력 생신·제사 자동 반복, D-day·다가오는 날, 관리비·공과금 납부일, 오늘 한눈에 홈, 큰 글씨 보기
- 가족 비서 팩(PRO): 거실 대시보드, 집안일 분담 카드, 칭찬 스티커, 아이 성장 카드, 가계부·월간 리포트, 냉장고 유통기한 + 다 쓴 품목 다시 주문하기(저장 링크·쇼핑몰 검색·AI 추천), 주간 식단 + AI 메뉴 추천, 가정통신문 사진 → 일정(AI)

## 가족 실시간 공유 켜기 (Firebase)
1. Firebase 콘솔 → 프로젝트(familyplaner) → **Firestore Database** 만들기
2. 규칙 탭에서 `families` 문서 읽기·쓰기를 허용 (예: `match /families/{code} { allow read, write: if true; }` — 가족 코드는 길고 추측하기 어렵게)
3. 프로젝트 설정 → 일반 → 웹 앱의 **프로젝트 ID**와 **웹 API 키** 확인
4. 앱의 **설정 → 가족 실시간 공유**에 프로젝트 ID, 웹 API 키, 가족 코드를 넣고 저장. 가족 모두 같은 코드를 넣으면 15초마다 서로 맞춰집니다.

## AI 기능
앱 안에 AI 키를 넣지 않습니다. 설정 → AI 연결에 가족 플래너 전용 서버 주소(예: Firebase Cloud Functions)를 넣으면 켜집니다. 서버는 `{prompt, image}`를 받아 JSON을 돌려주면 됩니다.
